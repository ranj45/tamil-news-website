# Tamil News Website 

A responsive Tamil-language news website built with pure HTML and CSS.

## Features

- Fully responsive — mobile, tablet, and desktop
- L-shape ad layout (right column + bottom strip)
- Live news ticker with clickable headlines
- Horizontal scrollable navbar
- Font Awesome icons
- Centered content layout above 1024px
- News detail page with comment section
- Related news section
- Pure HTML & CSS — no frameworks

## Tech Stack

- HTML5
- CSS3
- Font Awesome 6.5
- Google Fonts (Noto Sans Tamil)
